Mutlak Değer

Mutlak değer, öğrencilerin "işaretini at, pozitif yap" diye ezberleyip sonra sürekli yanıldığı bir konudur. Oysa tek bir cümlede saklı: mutlak değer, bir sayının sıfıra olan UZAKLIĞIDIR. Uzaklık asla negatif olamaz — mutlak değerin pozitif çıkmasının tek sebebi budur. Bu ünitede önce uzaklık sezgisini kuracağız, sonra içeriden çıkarken işaretin neden bazen değiştiğini göreceğiz, en sonunda da denklem ve eşitsizlik kalıplarını sistemleştireceğiz. Bir uyarı: mutlak değerli denklemlerde bulduğun her kök geçerli olmayabilir; sağlama bu konuda isteğe bağlı değil, zorunludur.

1) Mutlak Değer Nedir? — Uzaklık Fikri

TANIM — Bir gerçek sayının sayı doğrusu üzerindeki yerinin sıfır noktasına olan uzaklığına o sayının mutlak değeri denir ve |x| ile gösterilir. −4 sayısı sıfırdan 4 birim uzaktadır, 4 sayısı da 4 birim uzaktadır: |−4| = 4 ve |4| = 4.

CEBİRSEL TANIM — Uzaklık fikrini formüle dökersek:
|x| = x  (x > 0 ise)  ·  |x| = 0  (x = 0 ise)  ·  |x| = −x  (x < 0 ise)
Üçüncü satır kafa karıştırır: "−x negatif değil mi?" Hayır. x zaten negatifse −x pozitif olur. Örneğin x = −5 için −x = 5. Yani "−x" bir işaret değil, bir DÜZELTMEDİR.

İÇERİYİ AÇMA KURALI — Mutlak değer içindeki ifadenin gerçek değeri:
• 0'a eşit ya da 0'dan büyükse → mutlak değeri kendisine eşittir. |2| = 2  ·  a > 0 ise |4a| = 4a  ·  b < 0 ise |−3b| = −3b (çünkü −3b pozitiftir)
• 0'dan küçükse → mutlak değeri ters işaretlisine eşittir. |−13| = 13  ·  a > 0 ise |−7a| = 7a  ·  b < 0 ise |5b| = −5b
Kritik alışkanlık: "İçerideki ifade pozitif mi negatif mi?" sorusunu sormadan mutlak değeri açma. İşaret bilgisi verilmemişse iki durumu da ele almalısın.

2) Mutlak Değerin Özellikleri

#ÖzellikNeden / Not
1|x · y| = |x| · |y|Çarpımın uzaklığı, uzaklıkların çarpımıdır. İşaretler nasıl olursa olsun sonuç pozitiftir.
2|x / y| = |x| / |y|  (y ≠ 0)Bölme de çarpma gibi davranır; mutlak değer paya ve paydaya ayrı ayrı dağılır.
3|x| = |−x|Bir sayı ile ters işaretlisi sıfıra aynı uzaklıktadır. Bu yüzden |a − b| = |b − a|.
4|xⁿ| = |x|ⁿKuvvet, mutlak değerin dışına ya da içine serbestçe taşınabilir.
5|x + y| ≤ |x| + |y|  (üçgen eşitsizliği)Toplamada işaretler birbirini götürebilir, bu yüzden sol taraf küçülür. Eşitlik yalnızca x ve y aynı işaretliyken (ya da biri sıfırken) sağlanır.

DİKKAT — ÇARPMA DAĞILIR, TOPLAMA DAĞILMAZ: |x·y| = |x|·|y| her zaman doğrudur, ama |x + y| = |x| + |y| her zaman doğru değildir. Örnek: x = 5, y = −3 için |5 + (−3)| = 2 iken |5| + |−3| = 8. Çünkü toplamada zıt işaretler birbirini kısmen götürür. Sınavda "|x + y| = |x| + |y| ise" koşulu verilirse bu, x ve y'nin AYNI İŞARETLİ olduğu bilgisidir.

KAREKÖK BAĞLANTISI — Çift dereceli köklerde √(x²) = |x| yazılmalıdır, x değil. Neden? x = −3 alalım: √((−3)²) = √9 = 3, yani |−3|. Sonuç asla negatif çıkmaz, çünkü karekök sembolü daima pozitif kökü gösterir. Bu, TYT'de doğrudan sorulan bir ayrıntıdır.

EK ÖZELLİKLER — |x| ≥ 0 (mutlak değer negatif olamaz)  ·  |x| ≥ x (kendisinden küçük olamaz)  ·  |x| = 0 ⇔ x = 0  ·  |x| ≥ −x. Ayrıca |a| + |b| = 0 ise a = 0 ve b = 0'dır; çünkü ikisi de negatif olamayan iki sayının toplamı ancak ikisi birden sıfırken sıfır olur. Bu, iki bilinmeyeni tek denklemden bulmanı sağlayan güçlü bir kalıptır.

3) Kritik Nokta ve İşaret Tablosuyla Açma

Birden fazla mutlak değer içeren ifadelerde tek tek deneme yapmak yerine sistem kurarsın. Bunun aracı kritik noktalardır.

TANIM — Mutlak değer ifadesinin içini sıfır yapan değere kritik nokta denir. |x − 3| için kritik nokta 3, |2x + 4| için kritik nokta −2'dir. Kritik noktalar sayı doğrusunu bölgelere ayırır ve her bölgede içerideki ifadelerin işareti sabittir; bu yüzden mutlak değerler o bölgede tek bir şekilde açılır.

ÖRNEK (PDF) — |x + 3| + |x| + |2x − 4| ifadesinin en küçük değerini bulunuz.

  • Adım 1 — Kritik noktaları bul: x + 3 = 0 → −3,  x = 0 → 0,  2x − 4 = 0 → 2. Kritik noktalar: −3, 0, 2.
  • Adım 2 — Her kritik noktayı dene:
    x = −3 → |0| + |−3| + |−10| = 0 + 3 + 10 = 13
    x = 0 → |3| + |0| + |−4| = 3 + 0 + 4 = 7
    x = 2 → |5| + |2| + |0| = 5 + 2 + 0 = 7
  • Adım 3 — En küçüğü seç: 7. (Burada iki kritik nokta aynı değeri verdi; bu da 0 ile 2 arasındaki tüm x'lerde ifadenin 7 olduğunu gösterir.)
  • Neden minimum kritik noktada? Mutlak değerlerin toplamı parçalı doğrusal bir ifadedir; eğim yalnızca kritik noktalarda değişir. Dolayısıyla en düşük nokta ya bir kritik noktadadır ya da iki kritik nokta arasındaki düz bir parçadadır. Kritik noktaları denemek her durumda yeter.

4) Mutlak Değerli Denklemler

TEMEL KALIPLAR — x, a ∈ ℝ olmak üzere:
• a > 0 için |x| = a ⇒ x = a veya x = −a  (iki çözüm)
• a = 0 için |x| = 0 ⇒ x = 0  (tek çözüm)
• a < 0 için |x| = a ⇒ ÇK = ∅  (uzaklık negatif olamaz)
Aynı mantık |ax + b| = c denkleminde de geçerlidir: c < 0 ise çözüm kümesi boştur, hiç uğraşma.

İKİ MUTLAK DEĞER EŞİTSE — |f(x)| = |g(x)| denklemi iki sayının uzaklıklarının eşit olması demektir; bu da ya sayıların kendilerinin eşit olmasıyla ya da birbirinin ters işaretlisi olmasıyla mümkündür: f(x) = g(x) veya f(x) = −g(x). Örnek: |x − 1| = |2x + 3| → x − 1 = 2x + 3 (x = −4) veya x − 1 = −2x − 3 (x = −2/3). Her ikisi de geçerlidir.

TOPLAMI SIFIR KALIBI — |a| + |b| = 0 ise a = 0 ve b = 0'dır. Örnek: |x − 2| + |y + 5| = 0 ise x = 2 ve y = −5. Aynı fikir kareler için de çalışır (a² + b² = 0 ise ikisi de sıfır), çünkü ikisi de negatif olamayan büyüklüklerdir.

EN TEHLİKELİ DURUM — DEĞİŞKEN HEM İÇERİDE HEM DIŞARIDA: Sağ tarafta da bilinmeyen varsa, bulduğun kökler yabancı kök olabilir. Sebebi şu: mutlak değeri açarken "sağ taraf pozitiftir" varsayımını sessizce yapmış olursun; oysa bulduğun kök bunu bozabilir. Bu tip denklemlerde sağlama isteğe bağlı değildir.

ÖRNEK (PDF) — |2x − 9| = −4x + 3 denkleminin çözüm kümesini bulunuz.

  • Durum 1 — içerisi pozitif kabul: 2x − 9 = −4x + 3 → 6x = 12 → x = 2.
  • Durum 2 — içerisi negatif kabul: 2x − 9 = −(−4x + 3) = 4x − 3 → −2x = 6 → x = −3.
  • Sağlama (x = 2): |2·2 − 9| = |−5| = 5  ·  sağ taraf: −4·2 + 3 = −5.  5 = −5 YANLIŞ → x = 2 çözüme alınmaz.
  • Sağlama (x = −3): |2·(−3) − 9| = |−15| = 15  ·  sağ taraf: −4·(−3) + 3 = 15.  15 = 15 DOĞRU ✓
  • ÇK = {−3}. Neden x = 2 elendi? Çünkü o değerde sağ taraf −5 çıkıyor ve bir mutlak değer negatif olamaz. Sağlama yapmasaydın iki kök birden yazıp soruyu kaybederdin.
  • Kısayol: Sağ tarafın negatif olamayacağı koşulunu (−4x + 3 ≥ 0 → x ≤ 3/4) baştan yazarsan, x = 2 zaten koşulu sağlamadığı için elenir.

5) Mutlak Değerli Eşitsizlikler

Burada tek bir görsel kural her şeyi çözer: küçüktür ARADA, büyüktür DIŞARIDA. Sebebi yine uzaklık: "sıfıra uzaklığı a'dan az" demek bir aralığın içinde kalmak, "uzaklığı a'dan fazla" demek dışına taşmaktır.

SINIR DURUMLARI — Bunlar doğrudan soru olarak gelir, ezberlemek yerine uzaklık mantığıyla düşün:
• |x| < 0 → ÇK = ∅  (uzaklık negatif olamaz)
• |x| ≤ 0 → ÇK = {0}  (yalnız sıfırın uzaklığı sıfırdır)
• |x| ≥ 0 → ÇK = ℝ  (her sayı için doğru)
• |x| > 0 → ÇK = ℝ − {0}  (sıfır dışında her sayı)

ÖRNEK — |2x − 6| < 8 eşitsizliğinin çözüm kümesini bulunuz.

  • Adım 1 — "Küçüktür" olduğu için ARADA yaz: −8 < 2x − 6 < 8.
  • Adım 2 — Her tarafa 6 ekle: −2 < 2x < 14.
  • Adım 3 — Her tarafı 2'ye böl: −1 < x < 7 → ÇK = (−1, 7).
  • Geometrik okuma: |2x − 6| = 2|x − 3| olduğu için eşitsizlik |x − 3| < 4'e denktir: "x, 3'ten 4 birimden az uzakta" → 3'ün 4 birim solu ve sağı → (−1, 7) ✓
  • "Büyüktür" olsaydı: |2x − 6| > 8 → 2x − 6 < −8 veya 2x − 6 > 8 → x < −1 veya x > 7. Dikkat: iki parçayı "ve" ile değil "veya" ile birleştirirsin.

ÖRNEK (Tip 1) — a < 0 < b olduğuna göre |a| + |a − b| − |b| ifadesinin eşiti nedir?

  • |a|: a negatif → mutlak değeri ters işaretlisi → −a.
  • |a − b|: a negatif, b pozitif → a − b kesinlikle negatif → −(a − b) = −a + b.
  • |b|: b pozitif → b.
  • Birleştir: (−a) + (−a + b) − (b) = −2a.
  • Kontrol: a = −1, b = 3 alalım: |−1| + |−4| − |3| = 1 + 4 − 3 = 2  ·  −2a = 2 ✓ Somut sayı denemek, işaret hatalarını yakalamanın en hızlı yoludur.

ÖRNEK (Tip 7) — Bir sayının 7'ye uzaklığı 2'den küçük ise bu sayı hangi aralıktadır?

  • Adım 1 — Cümleyi sembole çevir: |x − 7| < 2.
  • Adım 2 — Arada yaz: −2 < x − 7 < 2 → 5 < x < 9.
  • Sezgi kontrolü: 7'nin 2 birim solu 5, sağı 9. Aradaki tüm sayılar 7'ye 2 birimden yakın ✓
  • Genel çeviri: "x'in a'ya uzaklığı" = |x − a|. Bu tek çeviri, sözel mutlak değer sorularının tamamını mekanikleştirir.

7) Kavram Sözlüğü

  • Mutlak değer: Bir sayının sayı doğrusunda sıfıra olan uzaklığı; |x| ile gösterilir ve negatif olamaz.
  • Uzaklık gösterimi: a ile b sayılarının birbirine uzaklığı |a − b|; simetriktir, |a − b| = |b − a|.
  • Kritik nokta: Mutlak değer içindeki ifadeyi sıfır yapan değer; sayı doğrusunu işaret bölgelerine ayırır.
  • İşaret bölgesi: İki kritik nokta arasında kalan ve içerideki ifadelerin işaretinin sabit olduğu aralık.
  • Üçgen eşitsizliği: |x + y| ≤ |x| + |y| bağıntısı; eşitlik yalnızca aynı işaretli sayılarda sağlanır.
  • Yabancı kök: Çözüm sırasında ortaya çıkan ama ilk denklemi sağlamayan, bu yüzden çözüme alınmayan değer.
  • Sağlama: Bulunan kökün ilk denklemde denenmesi; mutlak değerli denklemlerde zorunlu adımdır.
  • Parçalı tanım: Bir ifadenin, değişkenin bulunduğu aralığa göre farklı biçimlerde yazılması.

8) Sınavda Sık Karıştırılanlar

  • "Mutlak değer içindekini pozitif yap" demek: Doğrusu, içerideki ifadenin işaretine bakıp aynen ya da ters işaretle açmaktır. İşaret bilgisi yoksa iki durumu da yaz.
  • −x'i negatif sanmak: x < 0 iken −x pozitiftir. |x| = −x tanımı bu yüzden tutarlıdır.
  • |x + y| = |x| + |y| sanmak: Bu eşitlik yalnızca x ve y aynı işaretliyken geçerlidir; genel hâli ≤'dir.
  • √(x²) = x yazmak: Doğrusu |x|'dir; x negatif olabilir.
  • |x| = a < 0 durumunda çözüm aramak: Uzaklık negatif olamaz, doğrudan ÇK = ∅.
  • |x| > a çözümünü tek aralık yazmak: Çözüm iki ayrı parçadır; "veya" ile birleştirilir.
  • |x| < a çözümünü "veya" ile yazmak: Burada tek aralık vardır: −a < x < a.
  • Sağ tarafta değişken varken sağlama yapmamak: |2x − 9| = −4x + 3 örneğinde x = 2 yabancı köktür; sağlama yapılmazsa fark edilmez.
  • |f| = |g| denkleminde tek durum yazmak: Hem f = g hem f = −g incelenmelidir.
  • |x| ≤ 0 için boş küme demek: Doğrusu {0}'dır; sıfırın uzaklığı sıfırdır.
  • Minimum ararken kritik nokta dışında değer denemek: Mutlak değer toplamlarının minimumu daima kritik noktalarda (ya da aralarındaki düz parçada) oluşur.
  • |a| + |b| = 0 iken tek koşul yazmak: Hem a = 0 hem b = 0 olmalıdır.
  • Katsayıyı dışarı alırken mutlak değeri unutmak: |2x − 6| = 2|x − 3| doğrudur çünkü 2 pozitiftir; |−2x + 6| ifadesinde de 2|x − 3| olur, çünkü |−2| = 2.

9) Özet Kartı

  • Tanım: |x|, x'in sıfıra uzaklığı. |x| ≥ 0 ve |x| ≥ x.
  • Parçalı tanım: x ≥ 0 ise |x| = x  ·  x < 0 ise |x| = −x.
  • Uzaklık: a ile b arası |a − b|. "x'in a'ya uzaklığı k" → |x − a| = k.
  • Özellikler: |xy| = |x||y|  ·  |x/y| = |x|/|y|  ·  |x| = |−x|  ·  |xⁿ| = |x|ⁿ.
  • Üçgen eşitsizliği: |x + y| ≤ |x| + |y|; eşitlik aynı işaretlilerde.
  • Kök: √(x²) = |x|, x değil.
  • Toplamı sıfır: |a| + |b| = 0 ⇒ a = 0 ve b = 0.
  • Denklem: |x| = a → a > 0 iki kök, a = 0 tek kök, a < 0 boş küme.
  • İki mutlak değer: |f| = |g| → f = g veya f = −g.
  • Değişken sağda: Bulunan kökleri mutlaka sağla; yabancı kök çıkar.
  • Eşitsizlik: |x| ≤ a → −a ≤ x ≤ a (arada)  ·  |x| ≥ a → x ≤ −a veya x ≥ a (dışarıda).
  • Çift taraflı: a ≤ |x| ≤ b → iki simetrik aralık.
  • Sınır durumlar: |x| < 0 → ∅  ·  |x| ≤ 0 → {0}  ·  |x| ≥ 0 → ℝ  ·  |x| > 0 → ℝ − {0}.
  • Minimum: Mutlak değer toplamlarının en küçük değeri kritik noktalarda aranır.
